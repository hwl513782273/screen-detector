# 框选屏幕检测工具 v6.2（Screen Pattern Detector）

一个 macOS 原生（\.app 打包进 \.dmg）小工具：框选屏幕上某个窗口/区域，截取要找的
图案作为模板，**持续监控**该区域；当这些图案再次出现时**播放提示音**，可对每个
响铃结果进行**命中/误报反馈**以自动提升识别率。

## 本次 v6.2 更新（4 项）

1. **框选遮罩半透明（非全黑）**
   - 框选监控区域 / 框选添加模板时，整屏为约 30% 半透明蒙层，选区内用
     `CompositionMode_Clear` 擦除蒙层、露出下面的真实画面（spotlight 效果），
     并标注选区尺寸。不再是一团黑。

2. **顶部新增「关于」**
   - 点「关于」弹窗内按版本（v6.2 / v6.1 / v6.0 / v1~5）列出每次更新的功能说明。

3. **工具内实时显示命中状态**
   - 右侧「检测状态」面板：检测进行中每帧刷新 —— 命中显示绿色「🟢 命中」徽标 +
     最近命中对象与匹配度 + 时间；未命中显示灰色「⚪ 未命中」。不必等到响铃弹窗才知道。

4. **检测图案可预览**
   - 模板列表项带缩略图图标；选中某图案后，详情区显示其大图预览（精炼模板优先）。

## v6.1 / v6.0 既有功能（保留）

- v6.1：修复「+ 框选添加」「抓取该应用窗口」失效（详见 v6.1 版说明）。
- v6.0：响铃状态驱动（出现响铃 / 消失自动停 / 手动停）；多模板可管理；
  命中/误报自学习降误判；选应用自动抓窗口。
